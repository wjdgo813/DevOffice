## 이 폴더는 뭔가요

{{PRODUCT_NAME}}의 모든 것이 들어 있는 상자입니다.
**이 폴더 하나만 백업하면 전부 백업됩니다.**

안의 파일들은 직접 열어보실 필요 없어요. 대화로 만들고 고치면 됩니다.

## 폰에서 열어보려면

```
npx expo start
```

터미널에 QR 코드가 나옵니다. 폰의 **Expo Go** 앱으로 찍으면 바로 열립니다.
컴퓨터와 폰이 같은 와이파이에 있어야 해요.

## 내 폰에 앱으로 설치하려면

Expo Go 없이 진짜 앱처럼 쓰고 싶을 때입니다.

```
npx expo prebuild
npx expo run:ios
```

Xcode와 무료 Apple ID만 있으면 됩니다. 개발자 계정(연 $99)은 필요 없어요.

> ⚠️ **7일마다 다시 설치해야 합니다.** 무료 Apple ID로 만든 앱은 7일 뒤 열리지 않습니다.
> 매주가 번거로워지면 그때 개발자 계정을 생각해보시면 됩니다.

## 다시 시작하려면

터미널에서 이 폴더로 온 다음 `claude` 를 실행하고 `/devoffice` 를 부르세요.
지난번에 어디까지 했는지 알려드립니다.

## 주의

- `.env.local` 에는 비밀번호가 들어 있습니다. 아무에게도 보내지 마세요
- `.devoffice` 폴더에는 진행 기록이 들어 있습니다. 지우지 마세요
- **`EXPO_PUBLIC_` 으로 시작하는 값은 앱 안에 그대로 들어갑니다.**
  숨겨야 하는 값은 서버에만 두세요
