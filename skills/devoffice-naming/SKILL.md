# 제품 이름 정하기

이름은 **첫 화면 · 인터넷 주소 · 링크 미리보기**에 들어간다.

**위험은 하나뿐이다: 여기서 며칠이 간다.**
비개발자가 가장 오래 고민하는 일이 이름 짓기다. 빈칸을 주면 멈춘다.

---

## 후보를 먼저 만든다

**"이름을 정해주세요"라고만 묻지 마라.** PRD 내용에서 후보를 3개 만들어 제시한다.

```
마지막으로 이름을 정할까요?

  첫 화면이랑 주소에 들어가요.

  제가 몇 개 생각해봤어요:
   ① 동네나눔   ② 이웃창고   ③ 아파트나눔터

  마음에 드는 게 없으시면 직접 지으셔도 되고,
  지금 확 안 떠오르시면 ①로 하고 나중에 바꾸셔도 돼요.

👉 골라주시거나 직접 말씀해주세요
```

후보 만드는 방법: 한 줄 정의에서 **핵심 명사 2개를 뽑아 붙인다.**
길지 않게, 부르기 쉽게. 영어를 섞지 않는다.

---

## 영문 주소는 우리가 만든다

**사용자에게 영문 이름을 묻지 않는다.** 답을 못 한다.

한글 이름에서 슬러그를 자동으로 만든다.
- 소리 나는 대로 로마자 (동네나눔 → `dongne-nanum`)
- 소문자, 하이픈 구분, 20자 이내
- 이미 흔한 단어면 뒤에 짧은 구분자를 붙인다

```bash
devoffice state set product.name "동네나눔"
devoffice state set product.slug "dongne-nanum"
devoffice state set phase PRD
```

---

## 정해지면 무엇이 어떻게 되는지 알려준다

```
동네나눔 좋네요. 이렇게 쓸게요.

  화면에 보이는 이름   동네나눔
  인터넷 주소          dongne-nanum...   (제가 영어로 바꿨어요)

👉 다음으로 넘어갈까요?
```

폴더 이름은 말하지 않는다. 사용자가 볼 일이 없다.

---

## 나중에 바꾸고 싶다고 할 때

**무엇이 쉽고 무엇이 어려운지 갈라서 답한다.**

| 바꾸는 것 | 답 |
|---|---|
| 화면에 보이는 이름 | "바로 바꿔드릴게요" — 실제로 쉽다 |
| 인터넷 주소 (아직 공유 전) | "바꿀 수 있어요" |
| 인터넷 주소 (이미 공유함) | ⚠️ **"이미 보내신 링크가 전부 안 열리게 돼요"** |

마지막 경우는 `production.hasRealData` 가 `true` 일 때다.
**되돌리기 비싼 것**이므로 반드시 결과를 알리고 확인받는다.

```
주소를 바꾸면 지금까지 이웃분들께 보내신 링크가 전부 안 열리게 돼요.

 ① 화면에 보이는 이름만 바꾸기 (주소는 그대로)        ← 추천
 ② 주소까지 바꾸기 (기존 링크는 못 쓰게 돼요)
 ③ 그냥 두기
```

## 하지 말 것

- 이름을 정하라고만 하고 기다리기
- 영문 슬러그를 사용자에게 묻기
- 도메인 구입을 지금 권하기 (S9에서 한다)
- 이름이 마음에 안 든다고 평가하기
