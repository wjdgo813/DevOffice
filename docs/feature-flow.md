# 기능 하나가 만들어지는 과정

> v0.2 구현 전에 시나리오를 확정한다. Formula-Q 를 예로 든다.
> **사용자가 개입하는 지점은 기능당 2~3번이고, 나머지는 전부 자동이다.**

---

## 전체 그림

```
S5  기능 목록 정하기        ← 한 번만. 9개를 늘어놓고 순서 정하기      ★ 승인
─────────────────────────────────────────────────────────
S6  기능 하나씩  (9번 반복)
     ① 명세      무엇을 만들지 확정                              ★ 승인
     ② 계약·계획  CTO가 설계. 미결 사항이 있으면 한 번에 질문      (★)
     ③ 지시      작업 지시서 작성
     ④ 구현      서버 ∥ 화면 동시                                 자동
     ⑤ 통합      게이트 + 증거 대조                               자동
     ⑥ 검증      폰에서 직접 확인                                ★ 확인
     ⑦ 출시      커밋·배포·다음 기능 제안
```

★ = 사용자 차례. **기능당 2번 + 필요시 질문 1번.**

## S5 — 기능 목록 정하기 (한 번만, 10분)

**여기가 "기능 확정" 지점이다.** PRD의 9가지를 실제 작업 목록으로 바꾼다.

### 하는 일

1. **PRD의 기능을 늘어놓는다** — "~할 수 있어요" 사용자 문장으로
2. **순서를 정한다** — 의존성이 먼저, 그 안에서 가시성 우선
3. **타당성 3색을 매긴다** — 🟡🔴은 `research` 로 조사
4. **"빠진 게 있나요?"를 묻는다**
5. **크기를 본다** — 30분 넘을 것 같으면 미리 쪼갠다

### Formula-Q 예상 화면

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  만들 기능 정하기                 5/6
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

이 순서로 만들면 좋을 것 같아요. 총 9개, 일주일쯤이에요.

 1. 종목을 찾아서 담을 수 있어요     먼저. 담을 게 있어야 전략을 붙여요
 2. 담은 종목을 목록으로 봐요
 3. 준비된 전략 중에 고를 수 있어요

 ... 나머지 6개 (자세히 보기)

⚠️ 하나는 먼저 확인이 필요해요
   "종목을 찾는다"는 한국투자증권에서 종목 목록을 받아와야 해요.
   그게 되는지 5분만 알아보고 올게요.

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
👉 이 순서 괜찮으세요? 빠진 게 있나요?
```

> **"빠진 게 있나요?"를 반드시 묻는다.** 사용자는 목록에 없는 걸 스스로 못 알아챈다.
> 이름이 달라서 "있는 줄 알았다"가 흔하다.

**승인되면 `backlog` 에 저장되고, 그때부터 진척도(`3/9`)가 진짜 숫자가 된다.**

## S6-① 명세 — 기능 하나를 확정한다 (5분)

**진짜 확정 지점.** 여기서 승인해야 코드가 시작된다.

`spec.md` 가 만들어지고 `devoffice gate spec` 이 규격을 검사한다.
(가정 명세 있는가 / "안 만드는 것" 적혔는가 / AC가 5개 이하인가)

### Formula-Q F-001 예상 화면

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📋 종목을 찾아서 담기            1/9
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 확인된 것
   · 종목 이름으로 찾아서 내 목록에 담을 수 있다

🔵 제가 정한 것 ─ 이유
   1. 이름과 종목코드로 찾기        둘 다 쓰시니까
   2. 한 번에 20개까지 보여주기      더 많으면 폰에서 보기 힘들어서
   3. 이미 담은 종목은 표시          중복으로 담는 걸 막으려고
   4. 담기만 하고 지우기는 다음에    한 번에 하나씩 확인하시려고

❓ 이건 정해주셔야 해요
   A. 상장폐지되었거나 거래정지된 종목도 검색에 나올까요?
      ① 안 나온다 (헷갈리지 않게)                    ← 추천
      ② 나오되 회색으로 표시
      ③ 잘 모르겠어요 → ①로 진행할게요
      ※ 나중에 바꿀 수 있어요

이번에 만드는 것
   · 종목 검색 화면    · 검색 결과 목록    · 담기 버튼

이번에 안 만드는 것
   · 담은 종목 지우기 (F-002)
   · 종목 상세 정보 (백로그에 없음. 필요하시면 추가할게요)
   · 즐겨찾기

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
👉 골라주시면 만들기 시작할게요. 30분쯤 걸려요.
```

**"이번에 안 만드는 것"이 기대 차이를 미리 없앤다.** 그리고 여기 적힌 걸 만들면
나중에 CTO의 증거 대조에서 **범위 위반**으로 잡힌다.

## S6-② 계약·계획 — CTO가 설계한다 (자동, 3분)

사용자는 기다리기만 한다. CTO가 하는 일:

### ⓐ 계약을 코드로 쓴다

```
packages/contracts/F-001.ts     ← CTO 만 쓴다
  · 종목 검색 요청/응답 스키마
  · 담기 요청/응답 스키마
  · 엔드포인트 상수
```

**서버와 앱이 이 파일을 import 한다.** 규약 위반이 의견이 아니라
`tsc` 실패로 잡힌다. Formula-Q 는 앱과 서버가 물리적으로 분리돼 있어서
**이게 없으면 반드시 갈라진다.**

### ⓑ 작업을 쪼갠다

```
| ID | 담당     | 내용                  | 관련 AC |
| T1 | backend  | 한투 종목 검색 연동    | AC-1    |
| T2 | backend  | 담기 저장             | AC-3    |
| T3 | frontend | 검색 화면             | AC-1    |
| T4 | frontend | 결과 목록 + 담기 버튼  | AC-2,3  |
| T5 | frontend | 이미 담은 종목 표시    | AC-4    |
| T6 | frontend | 홈에서 이 화면 진입    | AC-5    |
```

**T6 같은 "진입 경로 연결"이 항상 마지막에 고정된다.**
기능을 만들었는데 거기로 가는 버튼이 없는 게 가장 흔한 누락이다.

### ⓒ 재사용을 조사한다

기존 코드를 실제로 뒤져서 지시서에 박는다.
구현 담당은 기억이 없어서, 여기 안 적히면 같은 걸 또 만든다.

### ⓓ 검증 준비물을 정한다

- 테스트 계정 (인증 있으면 2개)
- 시드 데이터 (제목 긴 것 하나 섞어서)
- 직링크

`devoffice gate plan` 이 이 넷을 검사한다. **비면 통과 못 한다.**

### 미결 사항이 나오면 — 여기서 한 번에 묻는다

계획을 짜다 보면 명세로는 결정 못 하는 게 드러난다.
**그때그때 묻지 않고 `plan.md` 의 "확인 필요"에 모았다가 한 번에 묻는다.**

3번 나눠 묻는 것보다 1번에 3개 묻는 게 훨씬 덜 피곤하다.

## S6-③④⑤ — 만들고 검사한다 (자동, 20분)

```
③ 지시    작업 지시서 (읽을 파일·담당 작업·재사용·경로 권한·막히면)
④ 구현    backend ∥ frontend 동시 — 계약이 잠긴 뒤라 안전하다
⑤ 통합    gate security → l1(타입·빌드) → l2(계약 스모크)
          그다음 CTO가 AC마다 파일:라인 증거를 댄다
```

**증거를 못 대면 미구현으로 간주한다.**

```
| AC   | 판정 | 근거                                    |
| AC-1 | ✅  | server/routes/symbols.ts:14             |
| AC-4 | ❌  | 근거 없음 — 이미 담은 종목 표시가 없음    |
```

❌ 가 하나라도 있으면 **사용자에게 가지 않는다.** 고치고 다시 대조한다.

이 동안 사용자는 이렇게 본다:

```
⏳ 만들고 있어요. 20분쯤 걸려요.
   화면이 조용해도 정상이에요.
```

## S6-⑥ 검증 — 폰에서 직접 확인 (사용자 차례)

**이게 "완료"의 정의다.** 테스트 통과가 아니라 사용자가 눌러본 것.

```
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  📋 종목을 찾아서 담기            1/9
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 만들었어요. 폰 화면이 알아서 바뀌었을 거예요.

🔑 확인용 계정 (제가 미리 만들어뒀어요)
   test@test.com / test1234

 1. 아래 [종목 찾기] 를 누르고 "삼성" 이라고 쳐보세요
    → 삼성전자·삼성SDI 같은 게 목록에 뜨면 정상이에요

 2. 삼성전자 옆 [담기] 를 눌러보세요
    → 버튼이 [담김] 으로 바뀌면 정상이에요

 3. 다시 "삼성" 을 검색해보세요
    → 삼성전자에 [담김] 표시가 그대로 있으면 정상이에요

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
👉 잘 되면 "네", 이상하면 뭐가 이상한지 말씀해주세요
   설명이 어려우면 화면을 캡처해서 붙여넣어 주셔도 돼요
```

**"네" 하기 전까지 다음 기능은 기계적으로 잠겨 있다.**
